# Vibe Coding How-To

This guide is for people who have never written a program. You will describe what you want
in plain English, and Claude Code will write the code. By the end you will have built a small
game and put it on the web.

The guide is being written now. The pages below will become links as each one is finished.

## Reading order

1. What vibe coding, Claude Code, the command line and GitHub are
2. Using the terminal on Mac, Windows or Linux
3. Installing Claude Code
4. Setting up GitHub
5. Using project-kit to keep your project on track
6. Building your first game

## Advanced topics

- Using Claude in Chrome to work in your web browser
- Letting Claude control your computer
- Using Claude to run other programs, such as Unity, Photoshop and Excel
- MCP servers, and how to use them
