# vibe-coding-howto

A beginner's guide to building programs with Claude Code and GitHub. You describe what you
want in plain English, and Claude Code writes the code. No programming experience needed.

**Read it as a website:** https://fbonds.github.io/vibe-coding-howto/

You can also read it here on GitHub. The guide lives in the [`docs`](docs/) folder, and the
website is built from those same files, so both always say the same thing.

## What the guide covers

1. [What vibe coding, Claude Code, the command line and GitHub are](docs/01-what-is-this.md)
2. [Using the terminal on Mac, Windows or Linux](docs/02-terminal.md)
3. [Installing Claude Code](docs/03-install-claude-code.md)
4. [Setting up GitHub](docs/04-github.md)
5. [Using project-kit to keep your project on track](docs/05-project-kit.md)
6. [Building your first game](docs/06-first-game.md)

Advanced topics:

- [Using Claude in Chrome to work in your web browser](docs/advanced/claude-in-chrome.md)
- [Letting Claude control your computer](docs/advanced/controlling-your-computer.md)
- [Using Claude to run other programs, such as Unity, Photoshop and Excel](docs/advanced/driving-other-apps.md)
- [MCP servers, and how to use them](docs/advanced/mcp.md)
