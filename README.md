# vibe-coding-howto

A beginner's guide to building programs with Claude Code and GitHub. You describe what you
want in plain English, and Claude Code writes the code. No programming experience needed.

**Read it as a website:** https://fbonds.github.io/vibe-coding-howto/

You can also read it here on GitHub. The guide lives in the [`docs`](docs/) folder, and the
website is built from those same files, so both always say the same thing.

## What the guide covers

The guide is being written now. Pages will be linked here as each one is finished.

1. [What vibe coding, Claude Code, the command line and GitHub are](docs/01-what-is-this.md)
2. [Using the terminal on Mac, Windows or Linux](docs/02-terminal.md)
3. Installing Claude Code
4. Setting up GitHub
5. Using [project-kit](https://github.com/fbonds/project-kit) to keep your project on track
6. Building your first game

Advanced topics:

- Using Claude in Chrome to work in your web browser
- Letting Claude control your computer
- Using Claude to run other programs, such as Unity, Photoshop and Excel
- MCP servers, and how to use them
